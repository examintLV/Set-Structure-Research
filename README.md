# Tennis Match Set-Outcome Analysis

This repository is for assessing which set-score outcome is more plausible for a tennis matchup. It is not a research-protocol repository. Start with [`PLAYER_ANALYSIS_GUIDE.md`](PLAYER_ANALYSIS_GUIDE.md).

For a best-of-three match, compare these four outcomes from the named player's perspective:
- Win 2–0 (straight-sets win)
- Win 2–1
- Lose 0–2 (straight-sets loss)
- Lose 1–2

Use the match format that will actually be played. Do not mix best-of-three and best-of-five records. Make a reasoned, evidence-based assessment; do not present a guess as a certainty or invent probabilities.
