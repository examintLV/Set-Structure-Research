# Instructions for AI Agents

Help assess tennis set-score outcomes for a specified matchup using the [`PLAYER_ANALYSIS_GUIDE.md`](../../PLAYER_ANALYSIS_GUIDE.md) at the repository root. Do not require numbered research filters, study IDs, or a formal research protocol.

Confirm the match format, surface, and players; use verifiable, relevant evidence; state sample sizes and missing information; compare outcomes from the named player's perspective; and communicate uncertainty. Distinguish a likely match winner from the most plausible exact set score. Only provide numerical probabilities when supported by a documented, appropriately tested model. Never fabricate data, citations, or calculations. Do not use betting-market odds as evidence.
