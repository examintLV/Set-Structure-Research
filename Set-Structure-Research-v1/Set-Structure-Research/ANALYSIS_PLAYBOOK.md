# Analysis Playbook

## A. Profile the sample first
Report candidate matches, eligible completed matches, duplicates removed, walkovers excluded, retirements separated, uncertain scores, and distributions by tour, level, year, surface, format, and draw type.

## B. Build standard tables
1. **Sample composition:** match counts and completeness by tour/level/surface/format.
2. **Historical structure:** count and share by conventional set count, denominator, uncertainty interval; match-tiebreak formats separate.
3. **First-set context:** first-set winner relative to final winner and match structure.
4. **Set competitiveness:** set position, scoreline, total games, absolute game differential, n.
5. **Tiebreaks:** tiebreak sets / eligible sets and matches with tiebreak / eligible matches.
6. **Serve/return by set:** numerator, denominator, rate, contributing matches, missingness.
7. **Deciding set:** only matches reaching a deciding set; score, game margin, tiebreaks, available set stats.

## C. Compare contexts
Before comparing, check comparable formats, data coverage, date windows, and definitions. For player comparisons, align periods, levels, surfaces, and opponent context where possible.

## D. Robustness
Repeat core tables with alternative retirement handling, main-draw-only rules, separate tours/formats, alternative time windows, and primary-source-only versus cross-checked samples.

## E. Write each finding
State population and period; n and denominator; observed result; uncertainty; confounders; and what cannot be inferred.

## F. Common errors
- Counting sets as independent matches.
- Mixing best-of-three and best-of-five.
- Treating match tiebreaks as ordinary sets.
- Presenting match-level stats as set-level.
- Treating missing as zero.
- Omitting denominators.
- Selecting only dramatic matches.
- Using current rankings for historical matches.
- Attributing differences to fatigue, motivation, injury, or psychology without evidence.
- Turning retrospective conditional rates into future forecasts.
- Including sportsbook or market information.

## G. Conclusion
Answer only registered retrospective questions. An inconclusive result is valid.
