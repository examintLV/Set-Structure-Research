# Quality Control and Audit Checklist

## Before collection
- [ ] Question, population, date range, tour, level, discipline, surface, format, and status rules predeclared.
- [ ] Primary and secondary outcomes identified.
- [ ] Retirement, walkover, default, and abandoned rules defined.
- [ ] Sources selected.
- [ ] No market/odds variables included.

## Record integrity
- [ ] Stable match IDs and traceable sources.
- [ ] Dates, event, players, and status checked.
- [ ] Duplicate candidates reviewed.
- [ ] Set scores and order reconciled.
- [ ] Match tiebreaks distinguished.
- [ ] Unknown values are not fabricated.

## Statistics
- [ ] Every percentage has numerator and denominator.
- [ ] Every table displays n.
- [ ] Missing is not zero.
- [ ] Match-level stats are not called set-level.
- [ ] Sets within matches are not treated as independent matches.
- [ ] Formats and disciplines separated.
- [ ] Small subgroups flagged.
- [ ] Uncertainty method stated.
- [ ] Multiple comparisons acknowledged.

## Interpretation
- [ ] Findings limited to sample and period.
- [ ] Association is not called causation.
- [ ] No unsupported motivation, fatigue, injury, or psychological claims.
- [ ] No future-match forecast or exact-set pick.
- [ ] No odds or market-derived data.
- [ ] Conflicting evidence disclosed.

## Reproducibility
- [ ] Raw data preserved separately.
- [ ] Extraction date/method recorded.
- [ ] Dataset fingerprint and schema version recorded.
- [ ] Code/dependency versions recorded.
- [ ] Corrections audited.
- [ ] Report reproducible from documented inputs.

## AI audit
- [ ] Source facts distinguished from interpretation.
- [ ] Material factual claims cited.
- [ ] No invented URLs, statistics, or tool-use claims.
- [ ] Inaccessible records disclosed.
- [ ] Search snippets not treated as verified records.
- [ ] Independent agents share scope and cutoff.
- [ ] Agreement is not treated as independent verification when sources overlap.

## Release gate
Do not release if core scores are untraceable, sample rules unclear, denominators missing, source conflicts hidden, incomparable formats mixed without separation, odds included, or prospective gambling claims made.
