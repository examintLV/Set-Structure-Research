# Source Standards

## Hierarchy
Prefer sources in this order, while verifying that each source actually contains the field being used:
1. Official tour, federation, tournament, or governing-body match records and statistics.
2. Official event result books, match-stat PDFs, and scoring systems.
3. Reputable specialist tennis databases with transparent match-level records.
4. Established statistical projects with documented methods and provenance.
5. Reputable media for contextual facts absent from official records.

Search snippets, social posts, forums, fan pages, and unattributed spreadsheets are leads only, not sufficient final evidence for core scores or stats.

## Source requirements
A source should be directly relevant, traceable to a stable URL or ID, clear about match-level versus set-level scope, and retrievable with a documented timestamp. Do not assume one provider covers every tour, level, or year equally.

## Cross-check
Cross-check unusual scores, retirements/defaults/walkovers, match-tiebreak formats, inconsistent player names/dates, and set-level stats that do not reconcile with match totals. Preserve disagreements and document resolution.

## Citations
For each material claim/table retain source name, direct record URL or ID, retrieval date, supported fields, and verification status. A tournament homepage is not a substitute for a match record.

## Licensing
Respect terms, API limits, copyright, and redistribution rules. If raw data cannot be redistributed, retain a source manifest and publish only permitted aggregates.

## Prohibited inputs
Never use sportsbook odds, bookmaker prices, betting exchange prices, market-implied probabilities, betting tipsters, or gambling-pick pages as analytical evidence. Do not import market data from pages that mix betting and match statistics.
